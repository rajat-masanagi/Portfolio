# Project artwork

The lunar concept illustration lives at `public/images/lunar-terrain.webp`. It was generated with the built-in image generation tool, then resized to 1200px and compressed to WebP. It is illustrative imagery, not project output or a dataset visualization.

Generation prompt:

> Create a landscape 3:2 editorial lunar surface illustration for a sophisticated software portfolio. Photographic overhead cratered lunar terrain, large shadowed crater lower left and intricate small craters, diagonally oriented swath reminiscent of satellite survey imagery. Restrained dark charcoal #101512, muted moss green #899477, warm gray and ivory highlights. Subtle translucent moss survey mask patches blending into terrain edges, fine subdued registration marks. Tactile film grain, dramatic raking light, highly detailed lunar geology. Full bleed composition, dark edges, no text, no labels, no logos, no routes, no arrows, no spacecraft. This is conceptual terrain imagery, not a navigation procedure. Calm premium scientific editorial aesthetic matching a dark forest charcoal portfolio.

Booking and workflow illustrations are editable SVG diagrams in `components/project-art.tsx`. They use the same charcoal, moss and ivory palette. Interface arrows and expand/close symbols live in `components/icons.tsx`; use these instead of Unicode symbols to avoid mobile emoji substitution.
